# AI Workflow Comparison Wordcap Mobile App

Image-based object and scene recognition for vocabulary extraction. The system is divided into multiple functional branches, each leveraging a different AI capability.

In addition to the product itself, this project investigates and compares different AI-assisted development workflows, focusing on tools such as VS Code AI, Cursor, and Google AI Studio, and evaluates their impact on development efficiency and developer experience.


## Project Outcome

### Outcome Type

* **Product**: AI-powered Wordcap-like mobile vocabulary application
* **Target Platform**: Android (iOS-ready architecture)

---
## Key Features

* Vocabulary saving and list management
* AI-generated definitions and explanations
* AI-generated example sentences
* Translation support for language learning
* Review and repetition to improve memory retention
* Local offline data storage
## Project Idea Overview

### Core Idea

This project is a mobile vocabulary learning app inspired by Wordcap and enhanced with AI capabilities. The app helps users:

* Save and organize vocabulary words
* Generate AI-powered explanations, translations, and example sentences
* Improve long-term memory using smart review and spaced repetition techniques

### Research & Engineering Goal

Beyond building the product, the project also aims to **compare different AI-assisted development workflows**, including:

* **VS Code + AI** – Ke Zhang & Eaint Mon
* **Google AI Studio** – Yue Chen
* **Cursor AI IDE** – Xuanyu Liu & Zhiying Huang
